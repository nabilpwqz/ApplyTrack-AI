# Software Requirement Specification (SRS)
## ApplyTrack-AI

### 1. Introduction
**ApplyTrack-AI** is a smart job application tracking system that helps users organize, manage, and analyze their job hunt process. It features AI-powered tools for job matching, resume analysis, and interview preparation.

### 2. Features
- **Authentication**: JWT-based secure user authentication with password reset and account management.
- **Kanban Board**: Drag-and-drop board for managing job applications across different stages (Applied, Interview, Offer, etc.).
- **Dashboard & Analytics**: Visual representation of application statistics and success rates.
- **AI Hub**: AI-driven features like job matching, resume analysis, interview preparation, and salary insights.
- **Company Tracking**: Monitor company health scores, layoff risks, and background information.
- **Reminders & Calendar**: Automated tracking of deadlines and upcoming interviews.
- **Admin Dashboard**: System administration for user management, role assignment, and platform statistics.

### 3. Technology Stack
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS, DaisyUI, React Query, React Router.
- **Backend**: Node.js, Express, TypeScript, MongoDB, Mongoose, JWT, Nodemailer.
- **AI Integration**: Google Gemini AI.
